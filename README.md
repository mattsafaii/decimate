# Decimate

A native macOS companion app for **Affinity Designer / Photo**. Affinity has no
programmatic image effects and can't run Photoshop plugins, so Decimate covers
that gap: it applies algorithmic effects to an image and round-trips the result
back into Affinity as a new layer.

The catalog focuses on the things Affinity *structurally can't do* — editable
vector output from raster input, and perceptual palette dithering — rather than
rebuilding filters Affinity already ships.

## How it works

Decimate drives Affinity V3 over its local MCP / JavaScript scripting bridge
(`localhost:6767`):

- **Pull** — exports the active Affinity document at full resolution to a temp
  file and loads it into Decimate's preview.
- **Effect** — pick an effect, adjust parameters, see a live (downsampled)
  preview.
- **Send** — renders at full source resolution and injects the result into the
  active document as a new layer: a **raster** layer for dithering, or
  **editable curves** for the vector effects.

MCP is the control channel; a Desktop temp file is the bulk-data channel. The
MCP client is written natively in Swift (SSE + JSON-RPC over `URLSession`) with
no third-party dependencies.

Decimate also works **standalone** — open an image, apply an effect, export
PNG/SVG — with no Affinity connection required.

## Effect catalog

| Effect | Engine | Output |
|---|---|---|
| **Vector Stipple** | Python / SciPy (weighted Voronoi) | editable vector dots |
| **Vector Engraving** | Swift (tone-following lines) | editable vector curves |
| **Vector Line-screen** | Swift (tone-driven ribbons) | editable vector curves |
| **Dithering** | Swift (palette + OKLab) | raster |

Dithering does nearest-palette matching in OKLab (perceptual) with a choice of
error-diffusion kernels (Floyd–Steinberg, Atkinson, Jarvis) or ordered Bayer,
plus bundled palettes and an in-session palette editor.

## Architecture

- **Swift + SwiftUI**, single Xcode app target, Apple Silicon, current macOS.
- The Xcode project is generated by **xcodegen** from `project.yml` — never
  hand-edit the `.pbxproj`. Re-run `xcodegen generate` after adding or removing
  files.
- Each effect is a *declaration* (name, engine, parameters, output type). The
  shell renders parameter UI and routes execution from the declaration, so
  adding an effect is additive — conform to `Effect` and list it in
  `EffectCatalog`.
- Engines: pure Swift for sequential per-pixel work (dithering, line effects);
  Python subprocess for numerical/vector algorithms (stippling), via a
  file-based CLI contract against an app-managed venv.

## Build & run

Requires Xcode and [XcodeGen](https://github.com/yonaskolb/XcodeGen)
(`brew install xcodegen`).

```sh
xcodegen generate
open Decimate.xcodeproj   # build & run in Xcode (⌘R)
```

On first launch Decimate creates a Python virtual environment under
`~/Library/Application Support/` from `python/requirements.txt` (NumPy + SciPy),
with visible progress. This blocks Python-engine effects until it finishes; the
rest of the app stays usable.

## Affinity setup

To use the Pull / Send bridge:

1. In Affinity, enable the **AI connector** (it serves `localhost:6767`).
2. In **Affinity → Preferences → General**, enable **"Allow scripts to access
   the filesystem."**
3. Grant **Decimate** access to your Desktop the first time it reads/writes the
   bulk-data temp file (macOS Files-and-Folders / Full Disk Access prompt).

Decimate shows a connection-status indicator with setup guidance when Affinity
is unreachable or access is blocked.
